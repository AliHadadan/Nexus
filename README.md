# Nexus — Interactive Awwwards-Inspired Website

A modern, visually engaging website inspired by award-winning web design. Built with React and Vite, featuring smooth animations, interactive components, and immersive video experiences.

## Overview

Nexus is a front-end development project focused on creating an engaging digital experience through modern UI design, animation, and interactive storytelling.

The project combines reusable React components, GSAP-powered animations, and multimedia assets to deliver a polished and dynamic user experience.

## Tech Stack

- **React 18** — Component-based UI development
- **Vite** — Fast development environment and build tool
- **JavaScript (ES Modules)** — Application logic
- **Tailwind CSS 4** — Utility-first styling
- **GSAP** — Advanced animations and motion effects
- **@gsap/react** — GSAP integration with React
- **React Icons** — Icon library
- **React Use** — Utility hooks
- **clsx** — Conditional class management

## Features

- Modern and responsive interface
- Smooth animations and interactive transitions
- Video-based visual sections
- Reusable and modular React components
- Dynamic navigation and content sections
- Immersive visual presentation

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/AliHadadan/Nexus.git
```

2. Navigate to the project directory:

```bash
cd Nexus
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Builds the project for production |
| `npm run preview` | Previews the production build |
| `npm run lint` | Runs ESLint |

## Build for Production

```bash
npm run build
```

The optimized production files will be generated in the `dist/` directory.
